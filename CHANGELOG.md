# Changelog

## Self-hosted fork — 2026-09-23

- Added Base45, Playfair, columnar transposition, and Base58/hex encoders.
- Added SHA3-256 and BLAKE2s-256 hashing.
- Added authenticated AES-GCM support and improved test coverage.
- Added an offline app shell, client-only pipe export/import, privacy page, and custom error pages.
- Added Vercel security headers and a permanent terminal-green theme.
- Disabled upstream pipe sharing until a self-hosted or client-only replacement is available.
- Preserved upstream attribution and the original MIT license.
